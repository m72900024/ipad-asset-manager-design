# iPad Asset Manager Design

Static design prototype for `m72900024/ipad-asset-manager`.

This repository contains a GitHub Pages-ready mockup board for the current iPad asset management system:

- Desktop 1440px management screens
- iPad 1024px field-use screens
- Dashboard, cart management, data editing, logs, MDM lookup, home entry, checklist, and modal states

## Local preview

Open `index.html` directly, or run:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
